### ESP LAMP
## принцип работы
1. Выдает своб точку доступа при первом включении с веб сервером на котором страница конфигурации wifi  
2. При заполнении стрницы пытается подключится к wifi и при невозмоности возвращает свою точку доступа  
3. При подключении к wifi пытается подключится к mqtt на топик /esp8266/commands
4. При успешном подключении получает команды on/off с python в зависимости от текущих секунд 
Веб сервер с переконфигурацией wifi также доступен и в режиме подключения к wifi  
В случае потери связи с wifi будет попытка переподкючения и при не обходимости включена своя точка доступа
